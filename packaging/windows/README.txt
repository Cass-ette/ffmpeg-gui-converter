FFmpeg GUI Converter (Windows)

How to distribute:
- Share this entire folder, not only the .exe.
- Users should double-click ffmpeg-gui-converter.exe.
- Put ffmpeg.exe and ffprobe.exe in the same folder as the .exe or in the bin\ folder.

Recommended layout:
  ffmpeg-gui-converter\
    ffmpeg-gui-converter.exe
    README.txt
    bin\
      ffmpeg.exe
      ffprobe.exe
